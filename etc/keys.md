# Nouns
- `Window`: Primary frame
  - `Pane`: Split window
: `View`: Secondary frame. Usuallyy toggleable

# Keymap Types
## Nav
  - 💥 `instantiation`: open/close
  - 🎯 `focusing`: activating window
  - 📐 `sizing`: fullscreen toggle
  - 📜 `scrolling`: down/up
  - 🤹🏻 `rearranging`: moving tabs/windows/panes, argslist
  - 🎈 `viewing`: toggling views
### In Page Movement
  - 🌪️ `warping`: cursor movement
     - 🐎 `scouting`: searching within a window
## Actions
  - `bot row`: undo, redo, copy, paste
  - `adjustment`: volume, brightness
  - `other`: git, view toggle, etc

# Universal Concepts
> [!note] most universal keymaps are baked into my kybd

- <A-SPC>: workstation switch
- <C-SPC>: tab/window switch
- `Scrolling`: qmk shortcuts
- `zx bot-row`: copy, paste, undo,
- `text edit`: word delete, jump word (C-left/right)
