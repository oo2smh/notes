# Steps
1. Image Systemization
  - Link idea/concept to an image
  - Create a legend
    - Use colors/art style for meaning
      - 🍒 Red: meaning, flow
      - ☀️ Yellow: usage, highlights
      - 🍊 Orange: categories
    - Art Style
      - Reality: Level 0
      - Movie Animation: Level 1
      - TV Animation: Level 2
      - Video Games: Level 3
        - 3d
        - 2d
  - Image linking (transitions between imgs)
2. Loci: Image placement into loci
  - shape journey
    - square, pentagon, hexagon, triangle, clock-circle
  - levels
    - the actual place: lvl 0
    - central area shape section: lvl 1
    - front of wall (corresponds to central area): lvl 2
    - on the wall itself (frames, tv, etc): lvl 3
      - mini-gate: to video-game world: lvl 4
3. Review
