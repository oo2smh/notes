# Anatomy
1. Repeatable action
- Base Case(s)
- Pre step(s): var setup
- Recursive Action: steps taken when pushing to call stack
- Post step(s): steps taken when popping from call stack

- Identify the smallest version of the repeatable problem to get base case

# Merge Sort Example
- Main actions: Break down big collection until it's fully sorted (has 1 or 0 items)
  - Merge each collection together until it's fully merged
  - return the merged collection
  - Simplest version of this problem: the collection has 1 or 0 items (BASE CASE!)

- The actions: Split, merge
- Recursive: Split
- Post step: Merge
