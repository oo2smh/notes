# Layers
> Comp-sci is broad, so it's easier to digest by breaking it down into 3 layers

- `Hardware`: Physical components of a computer
- `Software`: Programs and applications. Including the OS
- `Network`: OSI, TCP/IP

## *HARDWARE 🧱*
> Physical Anatomy of a computer. All major parts are stored on a circuitry board called a `motherboard`

### Motherboard Components
- `CPU`: the brain of the computer. Consists of 3 modules
  1. `Base`: ctrl-unit, alu
  2. `Time`: clock (heartbeat 🫀), timer (counts the heartbeats. heartbeat allocator ⏱️)
  3. `Memory`: registers (workbench), cache (tool-box), MMU (librarian)
- `RAM`: short-term memory
  - `Kernel space`: where the active OS modules are inputted
    - `Modules`: resources management: [mem, ps], file system, IO, network
      - `PS Module`: PS scheduler, dispatcher
      - `IO Module`: device drivers, interrupt handlers
      - `File System Module`: manages files (translation, access ctrl, journaling)
      - `Network Module`: Implements the TCP/IP stack. Routes packets and where they go
  - `User space`: holds processes: actively running programs
    - `Process`: composed of heap, stack, data, text
- `Persistent Storage`: long-term memory
- `ROM/BIOS`: startup script
- `IO ports`: openings for other IO devices
- `Bus`: UPS system. Roads/paths that connect the different parts of the motherboard

## *SOFTWARE 🧸*
> The programs that run on the hardware. Three types of softwares: system, programming, and applications. System software comes baked in with the computer. Applications are often optionally added (although some do come bundled depending on the OS)

### System (Foundational )
0. `Firmware(BIOS/UEFI)`: BIOS on motherboard
1. `Operating System`: manager of hardware, and all other softwares
3. `Shell`: Certain ones come bundled like c, gcc
4. `Device drivers`: software that allows hardware or certain IO devices to work

### Programming
> used to create other softwares

1. `Software Development Kit`: Bundle of tool for a specific language or platform
  - Front-end compiler (lexing, parsing)
  - Prebuilts: API of prewritten code to make writing easier
  - Runtime: code that provides the environment that runs the actual code
    - might contain a virtual machine (ie java)
    - Language Translator (interpreter or back-end compiler)

  - Example includes `Python SDK` or `Javascript SDK`

### Application
> softwares that the general public can use (no specialized knowledge needed)

- Browser, productivity specialized
- 🧪 Word, Chrome

## *NETWORK 🪢*
> A method to connect different computers together. Rules aka protocols are needed to facilitate networking.

- Historically, computers were connected with *wires*. Now, however, computers are mainly connected wirelessly. Through connections, data can be transferred.
- The Internet is the archetypical example of a practical use of networking!
- 2 main models to describe and organize networking.
  1. `OSI`: Open System Interconnectedness
  2. `TCP/IP`: Transfer Control Protocol/Internet Protocol Model
- `OSI` is a more broad/theoretical model of networking while `TCP/IP` is a more practical model focused on the Internet. Both can be combined into a Combined Model

### Combined Model
| TCP/IP         | OSI                                 |
|-----------    | ----------------------------------- |
| Application    | Application, Presentation, Session  |
|Transport      | Transport                           |
|Internet       | Network                             |
| Network Access | Data Link, Physical                 |
