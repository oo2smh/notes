# 🔨 Background Knowledge
> A brief understanding of hardware is needed in order to understand how the OS works. Notably, it is important to know the CPU, RAM, and persistent storage.

## Startup Process
- The `firmware` resides in ROM either as BIOS and UEFI. These are softwares programmed directly onto the chip.
  - This firmware is the first to start. It is the spark.
- It passes the baton to the `bootloader`: this is a small program stored in `persistent memory`
  - It loads the kernel code into `kernel space` of the RAM
    - Kernel is divided into different modules.
```toml
Process
Memory
IO & Drivers
File System
Network
```

# Programs and Processes
> All programs when activated becomes a process!

- `Programs`: 🧊 passive entity of code that resides in persistent storage
- `Process`: 🔥 active code that resides in RAM. (Text, Data, Stack, Heap)

```toml
Text: The actual code
Data: Global variables. Not all processes use this in this way
Stack: Running code
Heap: Slower, but more complex structures
```
