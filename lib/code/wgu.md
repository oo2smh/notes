## *GENERAL: COMPUTER SCIENCE*
- Computer Science: the study of computers through observation/experimentation
  - Different layers: hardware, software, networking
    - hardware: motherboard: cpu, persistent storage, RAM, IO ports, bus
    - software: systems / applications
      - Systems: Operating system, C libraries, device drivers
      - Applications: All other softwares such as browsers, text-editing, etc
    - networking
      - http protocol
      - OSI, TCP/IP protocol
