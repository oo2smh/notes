# Tldr 🐧
- **What**: 2 types of organizations will be covered here. Inner and Inter file organization. Inner organization is done mainly through `classes` and `functions`. Inter organization is done through `import/export`
- **Why**: This is a common pattern found in most languages.

# Import/Export
> I will use python as an example, but the other languages should be similar, at least in principle

## Language Examples
```py
# IMPORTS
import math
import math as m
from math import sqrt # selective export

# SELECTIVE EXPORT
__all__ = ["add", "subtract"] # Only these are "exported" for * imports
# otherwise when you import, everything in the file is imported
```

```js
import from '.utils/js' // will use default exports
import { logRealEstate, calculateCommission } from './utils.js';

// Explicit export model (must export the vars you want included)
export const name = "Eddy";
export function greet() { ... }
export default ... // if import is not specific, default exports are used from file
```

```go
// IMPORT
import "fmt" // stdlib
import "github.com/google/uuid" // 3rd party
import m "math" // m.sqrt()
import . "math" // sqrt() .. use math functions without prefix. Discouraged. Pollutes namespace

// if it starts with a capital letter, it is exported
func Exported()
func private()
```

## Protections
- When a file is imported, the imported files are ran once. In a typical workflow, you isolate a functionality or a group of functionality within a file. You ensure that the module is a self-contained piece of behavior before you import. When you import, you do not want to run the code necessarily. Rather, you want to merely gain access to the helper functions. To PREVENT the imported code from running outside of a file, you can use an `entry point guard`. Some languages have `implicit import guards` :such as `golang`

```py
if __name__ == "__main__": main()
```

```js
if (require.main === module) { main(); }
```

## Multimports
```py
fileA - import file B, file B.1
fileB -
fileB.1 - import file B
```

- File A imports File B twice. Once directly, and once when importing file B.1!
- Most languages solve this problem of multiple import inclusions by `module caching`.
  - python searches its cache first in `sys.modules`. Js searches its `module map`.
  - if not in list, the module is ran and then added to the cache
