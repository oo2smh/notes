# 🦜 1 Program Syntax DNA
## *TOKENS LITERAL*
> atomic piece of a programming language: literals, vars, operators, reserved words

```py
# LITERALS
## *PRIMITIVES*
number = 2 + 4.0 # int and float
boolean = True or False
string = "word"
nullish = None # also undefined, null

## *COMPLEX COLLECTIONS*
dynamic_array = [1,2,3]
dict = { a:1, b:2, c:3 }
tuple = (1,2)

# VARS
container = "elem to store"

# RESERVED WORDS (cannot use as an identifier)
if = "cannot use some words" # words like if are reserved.

# INVISIBLES
invisibles = ("whitespace", "comment", "tab")
```

## *TOKENS OPERATORS*
- active enforcers (verbs)
```py
# LCACA (Logical, Comparison, Assignment, Concat, Arithmetic
logical = (True && !False) && (True or False) # and/or/not (for py)
comparison = (0 < 1 and 0 <= 0) and (1 > 0 and 1 >= 1)
concat = "cheer" + "ios"
arithmetic = (1 + 1) + (1 - 1) * 1 / 1**2 % 2

# Fn call, member-access
fn_example(arg1, arg2) # fn call
dict = { a: 1, b: 2}
dict.a or dict[b] # membership access

# Identity (is/not is, ==/=== ) , Membership (in, .includes)
print(a in dict, a is not b)

# Other std lib operator shorthands (lang-dependent)
... # spread/rest
```

## *EXPRESSIONS*
> Phrase. Evaluates to a value. A value is a meaningful chunk of data in a programming language.

```md
1. Operator Based
- When operator tokens are used. They evaluate to a value (aka returns a value)
2. Literals
- Tokens that are simple values (4, "hello") are considered atomic expressions
3. Reserved Words
- Certain reserved words evaluate to a value
```

## *STATEMENTS*
> Performs an action (usually referred to as a side effect). `Side effect`: Any change other than returning a value (modifies a variable, mutate data structure, input/output, raising exception)

```py
# CTRL FLOW
jumps = ["break", "continue", "return", "throw"]
conditionals = ["if", "else", "elif", "switch", "ternary"]
loops = ["while", "for", "do while"]

# DECLARATIONS
declarations = ["variable", "constant", "function", "class"]

# DUAL CITIZENS (expressions with side effects)
dual_citizens = ["assignment", "fn_call", "new", "inc/decrement"]
```

## *ORGANIZATION DNA*
> Various ways to organize within a program for better readability and maintainability
> [!Important] Usually you import/export files (or specific portions of the file)

```py
# WITHIN A FILE
inner_file = ["function", "class"]

# MACRO ORGANIZATION
macro_organization = ["file/module", "directory/pkg"]
```

# 📔 2 Standard Library
> API collection of commonly used methods/properties. A collection of prewritten code that you can use. Most of the pre-built code is written in the Standard Library. But some are built in (using a lower level lang "c") for performance issues.

- `ADT`: Abstract data type. Computer scientists theorized about what data structures would be helpful. These ADTs when implemented are `data structures`. When a data structure is built into the language as a core feature, it is considered a `data type`

## *TYPE CONSTRUCTORS*
> Types are defined along with the common operations, properties within them.

### Primitives
```yaml
- Number (int, float)
- Boolean
- String* # some languages consider this to be a pseudo-primitive
- Nullish (null, undefined)
```

### Complex
```yaml 🎀 CATS Dogs
- Classes
- Array (dynamic)
- Tuples
- Set
- Dict
```

## *UNIVERSAL OPERATIONS*
> Most `ADT`s have some/most of these operations
~~~yaml
➕/➖: add/subtract to data structure
🔎: get/find current elem(s)
💱: swap current value
📏: size (gets count of num of elements) in data structure
🦋: transform to a different datatype (split/join)
🗑️: empty/clear current data structure
🥇: peek at 1st/last elem

## *TYPE CONVERSIONS*
datatype(🪙): converts 🪙 to specified datatype.
py: str(), bool(), dict(..),
js: String(), Boolean(), Object(..)
go: string(), bool(), map(..)
~~~

## *SEQUENCE ADT*
> The most commonly used group of ADTs. It consists of arrays and strings.

### Common Operations
```yaml
👇🏻: Indexing
🔪: slicing aka grabbing subslice of the whole
😺: concat (combine 2 or more of the same sequence to create the whole)
```

### Array Only
```yaml
🌓: sort
🔪: slicing aka grabbing subslice of the whole
🍤: reduce. Boil down whole to smaller value based on fn
```

### String Only
```yaml
🧙🏻: manipulate (trim, casing, etc)
```
