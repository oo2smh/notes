# Containerization
- It bundlers the runtime, (lang version), dependencies, the env variables, network settings. A VM spins up a new OS. Docker container is lighter because it doesn't sandbox the OS, but provides most of the benefits of a VM.

- `Kubernetes/AWS ECS` tools used to orchestrate many containers when there are a lot of open docker containers. Scalability.
